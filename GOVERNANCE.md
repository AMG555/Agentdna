# Governance

AgentDNA is developed in the open. Technical decisions should be documented in issues, design notes, or pull requests so contributors can understand the reasoning.

Maintainers are responsible for:

- Reviewing code quality and tests
- Protecting privacy defaults
- Reviewing security-sensitive changes
- Maintaining release documentation
- Keeping the project accessible to contributors

Changes involving observation, cloud data, credentials, automation, or user consent require additional privacy and security review.

Community contributions are encouraged. The project should favor small, composable modules over opaque behavior and should never trade away user control for convenience.
